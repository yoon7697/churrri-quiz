# 우리 반 퀴즈왕 v0.2

교사 화면 하나로 진행하는 수업 마무리 모둠 퀴즈입니다. 기존 포트폴리오와 오목 프로젝트에 영향을 주지 않는 별도 프로젝트입니다.

퀴즈 선택 → 2~12모둠·이름·생각 시간 설정 → 문제 → 정답·해설 공개 → 맞힌 모둠 선택 → 점수 확정 → 전광판 → 다음 문제 → 최종 결과.

- 문제마다 정답 모둠 +10점, 오답 0점입니다. 동일 문제를 다시 확정하면 기록을 교체해 중복 가산을 막습니다.
- 타이머 만료로 정답이나 다음 문제를 자동 공개하지 않습니다.
- 현재 문제의 점수 수정, 새로고침 후 선택과 진행 상태 복구, 공동순위를 지원합니다.
- 예시 5문제와 직접 문제 작성·수정·복제·저장·삭제·JSON 파일 내보내기/가져오기를 제공합니다.
- 데이터는 이 브라우저에 저장합니다. 다른 기기에서는 퀴즈 파일을 가져와 사용합니다. 브라우저 저장소 삭제·시크릿 창 종료 시 데이터가 유지되지 않을 수 있습니다.
- 수업 내용 또는 PDF에서 읽은 글로 AI 문제를 생성합니다. 난이도 설정은 없고, 학습 1~10문제 + 넌센스 0~3문제를 선택합니다. 정답·해설을 교사가 확인한 뒤 저장합니다.

빌드 없는 HTML/CSS/JS입니다. dist/가 정적 루트입니다. npm test로 Node 내장 테스트를 실행합니다. 모델·화면 템플릿·이벤트 처리를 각각 model.js, views.js, app.js로 분리했습니다.

실제 Chrome에서 예시 5문제 완료, 정답·해설, 모둠 선택, 10점, 점수 수정 후 중복 없음, 선택 중 새로고침과 복구, 최종 공동순위를 확인했습니다. 직접 문제 작성·저장·내보내기도 확인했습니다. 파일 가져오기의 브라우저 확인은 파일 선택 중 환경 연결이 초기화되어 미완료이며 데이터 형식 검사는 자동 테스트로 확인합니다. 실제 태블릿·전자칠판·학교 수업에서의 진행은 아직 미검증입니다.

## Vercel 배포

운영 주소: https://churrri-quiz.vercel.app/

별도 Vercel 프로젝트 `churrri-quiz`에서 운영합니다. Framework: Other, Build Command: `npm run build`, Output Directory: `dist`, Install Command: `npm install --ignore-scripts`입니다. 배포에 API 키나 로그인은 필요하지 않습니다. GitHub 저장소를 연결하면 main 브랜치 업데이트 때 자동 배포합니다. `.openai/hosting.json`은 이전 미리보기용 설정으로 Vercel 배포에는 포함하지 않습니다.

이전 미리보기에서 만든 퀴즈는 자동으로 옮겨지지 않습니다. 이전 주소에서 퀴즈 파일을 내보낸 뒤 새 주소에서 가져와 주세요.

## AI 문제 생성

`api/generate-quiz.js`는 Vercel Node Function입니다. AI SDK를 통해 Vercel AI Gateway의 `openai/gpt-6-luna` 모델을 사용하며 `AI_GATEWAY_MODEL`로 바꿀 수 있습니다. 서버는 Vercel OIDC 인증을 사용합니다. Vercel 외부에서 개발할 때만 서버 환경의 `AI_GATEWAY_API_KEY`가 필요합니다. 키를 브라우저나 GitHub에 넣지 마세요. Gateway 계정 확인 또는 크레딧 설정이 필요할 수 있습니다. 결제 수단·크레딧 구매·자동 충전 설정은 이 코드가 변경하지 않습니다.

AI는 외부 서비스이므로 수업 자료가 Gateway 및 모델 제공자에 전달됩니다. 원본 PDF는 업로드하지 않고 PDF.js가 기기에서 추출한 텍스트만, 교사가 생성 버튼을 눌렀을 때 전송합니다. 이 앱의 서버는 자료를 파일·DB·앱 로그에 저장하지 않습니다. 외부 제공자의 보관 정책은 별도입니다. 스캔/OCR은 지원하지 않습니다. PDF.js는 npm lockfile로 버전을 고정하고 빌드 시 자체 호스팅 파일과 라이선스를 복사합니다.

서버는 요청 범위·JSON 형식·정확한 문제 수·중복 보기·원문 인용 근거를 검사합니다. 생성과 별도 검토의 두 AI 호출에서 답이 다르거나 애매하다고 판단하면 결과를 보류합니다. 이것이 사실 정확성을 보증하지는 않으므로 교사가 초안을 확인해야 합니다. 질문·보기 수정 후 참고 근거는 생성 당시 설명임을 표시합니다. 생성 실패 시 자료를 유지하고, 성공한 결과도 자동 저장하지 않습니다. 생성한 초안은 기존 편집기를 통해 브라우저 저장소에 저장하며, 파일 내보내기와 기존 10점 점수 규칙은 유지합니다.

한 요청의 자료는 16,000자, 출력 문제는 최대 13개, AI 호출은 재시도 없이 2회로 제한합니다. 서버 인스턴스당 동시 3개·IP당 시간당 6개/30초 간격의 메모리 제한을 둡니다. 이 제한은 여러 인스턴스에 걸친 전역 과금 한도가 아닙니다. 공개 이용량이 늘기 전에 Vercel AI Gateway 프로젝트 예산 한도를 별도로 설정하세요. 사용자가 기다리기를 취소해도 서버 AI 호출은 종료 시점까지 비용이 발생할 수 있습니다. 브라우저 동기화·회원가입은 없습니다.

검증: `npm run build`는 규칙 엔진과 AI 경계값·근거·독립 검토·API 오류·요청 제한 테스트를 실행합니다. 실제 외부 AI 요청 및 PDF 브라우저 검증 결과는 배포 후 별도로 기록합니다.
