# 우리 반 퀴즈왕 v0.1

교사 화면 하나로 진행하는 수업 마무리 모둠 퀴즈입니다. 기존 포트폴리오와 오목 프로젝트에 영향을 주지 않는 별도 프로젝트입니다.

퀴즈 선택 → 2~12모둠·이름·생각 시간 설정 → 문제 → 정답·해설 공개 → 맞힌 모둠 선택 → 점수 확정 → 전광판 → 다음 문제 → 최종 결과.

- 문제마다 정답 모둠 +10점, 오답 0점입니다. 동일 문제를 다시 확정하면 기록을 교체해 중복 가산을 막습니다.
- 타이머 만료로 정답이나 다음 문제를 자동 공개하지 않습니다.
- 현재 문제의 점수 수정, 새로고침 후 선택과 진행 상태 복구, 공동순위를 지원합니다.
- 예시 5문제와 직접 문제 작성·수정·복제·저장·삭제·JSON 파일 내보내기/가져오기를 제공합니다.
- 데이터는 이 브라우저에 저장합니다. 다른 기기에서는 퀴즈 파일을 가져와 사용합니다. 브라우저 저장소 삭제·시크릿 창 종료 시 데이터가 유지되지 않을 수 있습니다.
- PDF 읽기·AI 자동 생성·난이도별 생성은 다음 단계입니다. 현재 그런 기능처럼 보이는 가짜 버튼은 없습니다.

빌드 없는 HTML/CSS/JS입니다. dist/가 정적 루트입니다. npm test로 Node 내장 테스트를 실행합니다. 모델·화면 템플릿·이벤트 처리를 각각 model.js, views.js, app.js로 분리했습니다.

실제 Chrome에서 예시 5문제 완료, 정답·해설, 모둠 선택, 10점, 점수 수정 후 중복 없음, 선택 중 새로고침과 복구, 최종 공동순위를 확인했습니다. 직접 문제 작성·저장·내보내기도 확인했습니다. 파일 가져오기의 브라우저 확인은 파일 선택 중 환경 연결이 초기화되어 미완료이며 데이터 형식 검사는 자동 테스트로 확인합니다. 실제 태블릿·전자칠판·학교 수업에서의 진행은 아직 미검증입니다.

## Vercel 배포

운영 주소: https://churrri-quiz.vercel.app/

별도 Vercel 프로젝트 `churrri-quiz`에서 운영합니다. Framework: Other, Build Command: `npm test`, Output Directory: `dist`, Install Command: `npm install --ignore-scripts`입니다. 배포에 API 키나 로그인은 필요하지 않습니다. GitHub 저장소를 연결하면 main 브랜치 업데이트 때 자동 배포합니다. `.openai/hosting.json`은 이전 미리보기용 설정으로 Vercel 배포에는 포함하지 않습니다.

이전 미리보기에서 만든 퀴즈는 자동으로 옮겨지지 않습니다. 이전 주소에서 퀴즈 파일을 내보낸 뒤 새 주소에서 가져와 주세요.
