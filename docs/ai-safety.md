# AI 무료 크레딧 보호와 미리보기 검증

2026-11-17 기준. 변경 사항은 `feat/ai-quiz-generation`에서만 검증하며 정식 배포는 별도로 결정합니다.

## 서버의 비용 보호

- API 키는 서버에서만 사용합니다. 키를 읽어 화면에 출력하거나 브라우저로 전달하지 않습니다.
- 무료 계정에서 실제 호출된 저비용 모델 `openai/gpt-4o-mini`를 고정합니다. 임의 모델 환경변수로 더 비싼 모델로 전환하지 않습니다.
- 생성과 정답 검토 각각을 시작하기 전에 Gateway의 실제 팀 잔액과 누적 사용액을 확인합니다. 확인 실패·시간 초과·잘못된 응답은 AI 호출 없이 중단합니다.
- 최초 무료 크레딧 $5 중 $1을 남겨 둡니다. 잔액 $1 미만 또는 누적 사용 $4 이상이면 새 모델 호출을 중단합니다.
- 잔액과 누적 사용액의 합이 $5를 넘으면 운영자가 확인할 때까지 중단합니다. 따라서 추가 구매뿐 아니라 다음 무료 크레딧 지급도 자동 승인하지 않습니다. 이 초기 보호 장치는 월별로 자동 초기화되지 않습니다.
- 생성 출력 7,500토큰, 검토 출력 2,200토큰까지이며 자동 재시도는 하지 않습니다. 수업 자료는 16,000자, 학습 문제 10개와 넌센스 3개까지입니다.
- 결제·크레딧 구매·자동 충전·플랜 전환을 실행하는 코드는 없습니다.

이 검사는 비용을 동시에 예약하는 중앙 장부가 아닙니다. 이미 시작된 동시 요청과 사용액 집계 지연 때문에 정확한 $4 차단선을 보장하지는 않습니다. 계정의 자동 충전 꺼짐과 API 키별 Gateway 예산은 별도로 확인해야 하며, 코드만으로 계정 청구 설정을 확인했다고 간주하지 않습니다. 특히 API 키 인증에는 프로젝트 OIDC 예산만 설정해도 적용되지 않습니다.

## 과다 요청 방지

- 미리보기 환경의 POST `/api/generate-quiz`에 Vercel 방화벽 제한을 적용했습니다: 같은 IP에서 10분당 6회. 서버 인스턴스가 달라도 적용됩니다.
- 애플리케이션에는 추가로 30초 간격, IP별 시간당 6회, 인스턴스당 동시 생성 3회의 제한이 있습니다. 이 메모리 제한은 인스턴스 재시작·추가 시 초기화되므로 서비스 전체의 시간당 제한이라고 안내하면 안 됩니다.
- 방화벽 규칙은 `preview` 환경만 대상으로 합니다. 정식 배포 승인 후 운영 환경에 적용할지 별도로 결정합니다.
- 학교처럼 하나의 외부 IP를 공유하면 여러 교사가 이 제한을 함께 사용한다는 점을 고려해야 합니다.

## 정답·PDF 검증 범위

- 문제 수·보기 중복·자료 인용·정답 인덱스를 먼저 검사하고, 별도 AI 호출이 표시된 정답 없이 문제를 풉니다. 검토가 불일치하거나 불완전하면 초안을 반환하지 않습니다.
- AI 검토도 정답의 완전한 보증은 아닙니다. 실제 점검 중 보기 설명의 부정확한 단정을 발견해 출제·검토 지침을 보강했습니다. 교사의 최종 확인이 필요합니다.
- PDF.js 호환 빌드와 호환 worker를 함께 배포합니다. 자동 테스트는 실제 한글 PDF의 텍스트 추출, 텍스트 없는 PDF, 손상·잘못된 형식, 10MB·50쪽·16,000자 제한을 검사합니다.
- 자동 PDF 테스트에서는 Node의 파일 읽기 방식에 맞춰 자료 파일의 주소만 로컬 경로로 바꿉니다. 웹 페이지에서 파일 선택부터 끝까지 진행한 시험과 구분합니다.
- 원격 브라우저의 파일 선택 창이 응답하지 않아, 실제 파일 선택 UI부터의 전체 PDF 흐름은 확인하지 못했습니다.

## 정식 배포 전 남은 계정 확인

브라우저 계정 화면이 로그인 화면으로 이동하여 다음 두 항목은 확인하지 못했습니다. 결제 정보나 API 키를 채팅으로 공유할 필요는 없습니다.

1. AI Gateway의 자동 충전이 꺼져 있는지 확인합니다.
2. 현재 API 키 또는 팀 예산을 무료 잔액보다 낮게 설정합니다. 예산도 진행 중인 요청이 완료될 수 있는 소프트 제한이므로 여유를 남깁니다.

유료 크레딧 구매·자동 충전 활성화·유료 플랜 전환은 하지 않습니다.

- 브라우저에서 학습 2문제 + 넌센스 1문제 생성 및 수정 화면 진입 성공. 그러나 아래의 넌센스는 사람의 검토에서 미통과입니다. AI 검토가 완전한 정답 보증이 아님을 실제로 확인했습니다.
  - 질문: “도대체 나무가 춤을 추면 어떻게 될까요?”
  - 표시된 정답: “나무가 방긋 웃는다”
  - 해설은 단지 상상 속 이야기라고 설명합니다. 이 보기가 다른 보기보다 유일하게 정답이라는 근거가 없습니다.
  - 따라서 넌센스 자동 출제 품질은 통과로 처리하지 않았고 정식 배포를 보류했습니다. 검증된 넌센스 문제 모음에서 선택하는 방식이 다음 보완 후보입니다.
- 브라우저에서 생성된 학습 퀴즈의 저장과 새로고침 후 유지도 확인했습니다.
- 실제 한글 PDF 추출과 제한 검사는 자동 테스트로 통과했습니다. 배포된 호환 PDF 모듈·worker·한글 CMap·폰트는 모두 HTTP 200이었습니다. 파일 선택 UI부터 이어지는 흐름은 원격 파일 선택 창 문제로 미확인입니다.
- 방화벽 실검증: 이미 허용된 생성 요청 2회 뒤, AI를 호출하지 않는 잘못된 입력 7회를 전송했습니다. 처음 4회는 입력 오류 400, 이후 3회는 `x-vercel-mitigated: deny`가 있는 429로 방화벽에서 차단됐습니다.
